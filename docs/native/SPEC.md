# APIKS Native — утверждённая спецификация

Источник требований: владелец, 04.10.2026, явная команда «старт».

Новая production-версия — Swift/SwiftUI/UIKit, AVFoundation/Core Image/Metal.
В интерфейсе и монтажном движке нет WebView, JavaScript и удалённо загружаемой логики.
Существующая тестовая версия, её bundle ID, файлы, ветка main и проекты остаются доступны.
Разработка ведётся в изолированной ветке native-production.

## Данные

Проекты принадлежат одному устройству. Оригиналы копируются в локальное хранилище приложения.
Для монтажа создаются восстанавливаемые копии до 1080p; финальный экспорт разрешает только оригиналы,
включая 4K. Отсутствие оригинала — понятная ошибка с предложением повторного импорта.
Видео, изображения, звук, проекты и их каталог не передаются на сервер. Резервное копирование
медиа в iCloud отключено. Удаление приложения удаляет локальные проекты; это объясняется в приложении.
Сохранение атомарное, с восстановлением последней корректной версии после прерывания записи.
Каталоги зарегистрированных пользователей изолированы; гостевой монтаж доступен без регистрации.

## Аккаунты

Sign in with Apple, Google Sign-In и подтверждённая почта. Собственный сервис на имеющемся сервере
хранит только учётные данные, сессии и события ограничения частоты запросов. Никакого Firebase,
платной SaaS-инфраструктуры, облачного хранилища видео и платного распознавания речи.
Секреты провайдеров находятся только на сервере; сессии iOS — в Keychain.
Удаление аккаунта доступно в приложении с отзывом сессий и Apple-токенов.
Удаление аккаунта не должно оставлять доступ к его локальному каталогу другому пользователю.
Отправитель писем определяется через доступный SMTP/DNS владельца; в тестах используется локальный транспорт.

## Редактор

Один EditorStore — единственный источник проекта и истории команд. Позиция воспроизведения
и временный выбор элементов отделены от сохранённой модели. Жест создаёт одну операцию undo.
Импорт, прокси, миниатюры, аудиоволны, сохранение и экспорт выполняются вне главного потока.
Проверка project ID и revision защищает от завершений устаревших фоновых задач.
Нажатия имеют области не меньше 44×44 pt и видимый результат; экспорт показывает прогресс и отмену.

Обязательные сценарии: видео/фото/аудио → таймлайн → обрезка/разрез/перестановка →
слои/текст/звук/скорость/эффекты/ключевые кадры → автосохранение → повторное открытие →
экспорт исходного разрешения → Photos/системное меню «Поделиться».
Дополнительные возможности существующего редактора фиксируются в FEATURES.md и проверяются
по отдельности. Функция без нативной реализации не считается перенесённой.

## Релиз

Новый bundle ID com.piks.app.native, отдельные App Group/Share Extension и запись App Store Connect
позволяют оставить тестовую версию установленной. Никаких изменений её профилей и подписания.
Xcode 26+ / iOS 26 SDK, privacy manifest, политика конфиденциальности, описание локального хранения,
фактические ответы App Privacy, удаление аккаунта и рабочий доступ для App Review.
Публикацию в App Store выполняет владелец. Нельзя называть сборку готовой до компиляции,
XCTest и проверки полного сценария на iPhone; производительность оценивается измерениями.

## Исходная проверка

570 модульных проверок исходного редактора прошли 04.10.2026.
Полный WebGL-прогон на Windows не подтверждён; известны две устаревшие картинки таймлайна.
Фундамент Ryndi заморожен и остаётся только источником для сравнения алгоритмов.
Windows не имеет Xcode/Swift: чистое Swift-ядро проверяется Linux-toolchain,
AVFoundation/UIKit — на Mac Codemagic. Эти проверки не взаимозаменяемы.
