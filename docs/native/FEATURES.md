# Нативные возможности — журнал соответствия

Источник требований: SPEC.md. Сводка выпуска и результаты проверок: STATUS.md.
«Реализовано» означает наличие нативного пути; проверка на настоящем iPhone
и полный перенос возможностей ещё не завершены.

| Возможность | Реализация | Проверка |
|---|---|---|
| Локальный каталог / автосохранение / восстановление | реализовано | Swift tests; полный сценарий перезапуска на iPhone ожидает |
| Оригиналы 4K / прокси до 1080p | реализовано | планы рендера, очередь прокси, экспорт 4K из оригинала проверены; длинные проекты ожидают |
| Импорт видео, фото, аудио | реализовано | тесты хранения и закрытого редактора; реальные Photos/Files ожидают |
| Share Extension для приёма файлов из других приложений | не реализовано | требуется отдельный target |
| Preview / scrub / timeline / split / trim / reorder | реализовано | компиляция UIKit/SwiftUI и тесты команд; полный сценарий на iPhone ожидает |
| Undo / redo / транзакции жестов | реализовано | Swift tests |
| Layers / crop / transform / opacity | реализовано | планы рендера и выборочные кадры; все сочетания эффектов ещё не проверены |
| Speed / source time mapping | реализовано | Swift + media tests |
| Volume / fades / channels / music | частично | усиление выше 100% в preview требует согласования с экспортом; проверка звука на iPhone ожидает |
| Базовая цветокоррекция / blur / sharpen / vignette / grain | реализовано | компиляция и базовый нативный рендер; покадровая проверка всех эффектов ожидает |
| LUT / настоящие перекрёстные переходы | не реализовано | сейчас transitionIn даёт только fade-in |
| Текст / ключевые кадры / формат холста | реализовано | ключевые кадры проверены сравнением пикселей; текст и панели компилируются |
| Субтитры / распознавание речи / запись озвучки | не реализовано | нужен собственный нативный путь без платного ASR |
| Retouch / background removal | не реализовано | нативная обработка отсутствует |
| Аудиоволны / кэш аудио для preview | не реализовано | требуется работа с памятью и измерение задержки |
| Export / progress / cancel / Photos / Share | частично | экспорт оригиналов 4K, паузы, фото и ранняя отмена проверены; поздняя отмена и системные сценарии ожидают |
| Apple / Google / подтверждённая почта / удаление аккаунта | частично | клиент, Keychain и собственный сервер проверены тестами; реальные провайдеры и SMTP не подключены |
| Область нажатия короткого клипа не меньше 44×44 pt | реализовано | XCTest геометрии и выбора; физический iPhone ожидает |
| Плавность таймлайна / offline / фон / память | не подтверждено на устройстве | требуется установленная сборка и измерения на iPhone |

Нельзя объявлять перенос завершённым по наличию кнопок или успешной компиляции.
