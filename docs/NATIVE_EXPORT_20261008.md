# Исправление экспорта, 8 октября 2026

Разрешение владельца: «Старт» на исправление зависшего экспорта, резервного пути и одну итоговую тестовую сборку.

Журнал: на 720×1280 / 74.6 с нативная обработка прекращается примерно за 0.48 с; старое сообщение сохраняло только localizedDescription. Точный NSError исходного отказа из этого журнала установить нельзя.

Изменения:
- Выходной пул RyndiCompositor получает один числовой BGRA вместо массива; массив остаётся допустимым на входе.
- Ошибка экспорта сохраняет этап и цепочку NSError domain/code. Незавершённый файл удаляется.
- mediaRead передаёт странице оригинальный файл порциями до 512 КБ; лёгкие копии монтажа не подменяют оригинал экспорта.
- Перед сборкой IPA CI проверяет настоящий экспорт синтетического full-range 720×1280 с B-кадрами: 1080×1920 / 25 fps, видео и стереозвук, целый клип и два фрагмента после разреза.

На Windows проверены YAML и git diff --check. Нативный сценарий должен пройти на Mac в CI; успешной проверкой на iPhone это не является. Повтор исходного экспорта владельцем нужен после установки сборки.
